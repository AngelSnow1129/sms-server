短信验证码中继，调用方无需接入短信平台

服务端从短信供应商回调中自动提取验证码并缓存；调用方只需按手机号轮询一个接口取码， 取走即焚。支持自托管（MySQL/SQLite）与 Cloudflare Workers + D1 免服务器部署。

一键部署到 Cloudflare 先试试取码助手 GitHub 仓库

功能特性

一条 webhook 收短信，一个接口取验证码，中间不需要你对接任何短信平台的 API。

密钥不落日志

验证码存储与日志全部脱敏：缓存 key 是 HMAC-SHA256(手机号) 的十六进制而非手机号本身，日志只记前 8 位指纹，不出现验证码明文与完整 token。

阅后即焚 + 对账窗口

验证码被取走即失效，第二次查询必为 pending。SQLite/D1 后端额外保留 10 分钟已读记录供对账「调用方说没收到码」，到点由清理协程物理删除。

存储可插拔

存储抽象为 Store 接口：内存实现零依赖即开即用，SQLite/MySQL 持久化一个环境变量切换；同一组契约测试保证切换不改语义。

三步接入

以 Cloudflare 一键部署为例，自托管（Docker + MySQL/SQLite）步骤相同，仅配置方式不同，详见接口文档。

部署服务，拿到两个密钥

点击页首「一键部署到 Cloudflare」，向导中填写 HMAC_SECRET 与 WEBHOOK_SECRET（生成：openssl rand -hex 32），部署完成得到 https://sms-server.<你的子域>.workers.dev。

让短信流向 webhook

把回调地址配置到短信来源：供应商回调直接用 /api/v1/webhook/sms/{WEBHOOK_SECRET}；安卓备用机可用 SmsForwarder 转发，对接教程见这里，支持按通道独立鉴权。

按手机号轮询取码

调用方在本地用同一个 HMAC_SECRET 算出 token，POST 到 /api/v1/otp 即可；命中返回验证码并立即失效。token 是收件人号码 + 密钥的确定性计算结果，不是服务端下发的配置——用下方取码助手或 token 计算页 生成命令。

取码助手

在浏览器本地计算 token 并生成可直接复制的命令。密钥与手机号只在当前页面内存中参与计算，本页不发出任何网络请求（Web Crypto 要求 HTTPS 或 localhost）。只需要算 token、或想弄清「哪些值要计算、哪些是静态设置」，到 token 计算页。
